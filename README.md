# Homebrew tap

schroneko projects の Homebrew Formula を配布する tap。

## xchat-cli

```bash
brew install schroneko/tap/xchat-cli
```

xchat-cli は Node runtime を同梱するため、利用者側の Node.js と npm は不要。Chrome DevTools Protocol にも依存しない。

使い方と source code は [schroneko/xchat-cli](https://github.com/schroneko/xchat-cli) を参照。
